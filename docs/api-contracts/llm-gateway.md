# LlmGateway / Adapter Internal Contract

Owner: BE-A

## Internal Interface

Description: Normalizes all model provider calls behind one internal gateway contract for AI review and LlmTrigger flows.

```text
LlmGatewayResponse review(LlmGatewayRequest request)
```

Request fields:

```text
providerId required
modelName optional, overrides provider.defaultModel
messages required, OpenAI-compatible role/content messages
```

Response fields:

```text
status
rawResponse
contentText
structuredJson
latencyMs
errorCode
errorMessage
```

## Status Values

```text
SUCCESS
PROVIDER_UNAVAILABLE
PROVIDER_ERROR
TIMEOUT
INVALID_JSON
```

Rules:

```text
Only enabled providers can be called.
Provider API key is decrypted only for the runtime call and is never returned.
Adapter sends POST {baseUrl}/chat/completions.
Provider custom headers are injected before Authorization is set.
Authorization is always normalized to Bearer <apiKey> when an API key exists.
Raw provider response is retained in rawResponse for troubleshooting and later Agent Run persistence.
```

## Structured JSON Extraction

```text
Gateway reads choices[0].message.content from the OpenAI-compatible response.
Content can be pure JSON or Markdown fenced JSON.
If content is not valid JSON, status=INVALID_JSON and rawResponse/contentText are preserved.
```

## Error Mapping

```text
Missing or disabled provider -> PROVIDER_UNAVAILABLE
Provider HTTP non-2xx or I/O failure -> PROVIDER_ERROR
Adapter timeout -> TIMEOUT
OpenAI-compatible body or model content cannot produce structured JSON -> INVALID_JSON
```

## Configuration

```text
labelhub.llm.gateway.timeout-ms
Environment override: LABELHUB_LLM_GATEWAY_TIMEOUT_MS
Default: 30000
```

## Metrics

AI model calls and business flows are instrumented with Micrometer. Metrics are available from Spring Boot Actuator after at least one AI call has been executed by the current application process.

```text
GET /actuator/metrics/labelhub.ai.requests
GET /actuator/metrics/labelhub.ai.latency
```

Metric tags:

```text
biz_type: LLM_GATEWAY, AI_REVIEW, PRE_ANNOTATION, LLM_TRIGGER
provider_id: provider id when known, otherwise unknown
model_name: model name when known, otherwise unknown
status: SUCCESS, FAILED, RATE_LIMITED, TIMEOUT, INVALID_JSON, PROVIDER_ERROR, PROVIDER_UNAVAILABLE, MANUAL_REQUIRED
error_code: backend/provider error code when present, otherwise none
```

Rules:

```text
labelhub.ai.requests is a counter for success, failure, timeout, invalid JSON, provider unavailable, provider error, rate limited, and manual-required outcomes.
labelhub.ai.latency is a timer in milliseconds for measured AI execution time.
Gateway-level metrics are recorded by DefaultLlmGateway.
Business-level metrics are recorded by AI review, pre-annotation, and LlmTrigger services.
```

Security:

```text
API Key must not appear in errorMessage, audit logs, application logs, rawResponse generated by backend, or public API responses.
```
