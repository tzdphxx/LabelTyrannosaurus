# 阶段二：Owner 闭环

## 目标

让任务负责人可以完成任务创建、数据导入、任务管理、发布配置和结果查看的基础闭环。

## 覆盖任务

- 任务 6：任务负责人仪表盘
- 任务 7：任务管理
- 任务 8：任务创建/编辑
- 任务 9：数据集导入与预览

## 实施内容

### 1. Owner 仪表盘

展示：

- 总任务数
- 进行中任务
- 待审核数据
- 异常数据
- 导出任务状态

### 2. 任务管理

实现：

- 任务列表
- 搜索和筛选
- 状态标签
- 任务详情入口
- 发布、暂停、结束等状态操作

### 3. 任务创建与编辑

支持配置：

- 标题
- 描述
- 富文本说明
- 标签
- 截止时间
- 奖励规则
- 分发策略
- 关联模板

### 4. 数据集导入与预览

支持：

- JSON / JSONL / Excel 文件入口
- 字段映射预览
- 样本数据预览
- 导入错误展示

## 产出

- Owner 可以看到任务总览
- Owner 可以创建任务草稿
- Owner 可以编辑任务基础信息
- Owner 可以查看导入数据预览
- Owner 可以切换任务状态

## 验收标准

- 任务负责人可以完成“创建任务 -> 配置基础信息 -> 导入数据 -> 预览 -> 发布”
- 列表筛选结果正确
- 状态操作有确认和反馈
- 导入异常能展示具体原因

## 风险

- 发布前如果模板未完成，需要阻止发布
- 导入数据字段可能和模板字段不匹配
- Owner 页面容易做成纯表单堆叠，需要保持工作台信息结构
