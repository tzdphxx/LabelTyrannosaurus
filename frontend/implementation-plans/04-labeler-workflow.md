# 阶段四：标注闭环

## 目标

让标注员完成从任务领取到作答、草稿、提交、查看打回并修改的完整闭环。

## 覆盖任务

- 任务 13：任务广场与领取
- 任务 14：标注工作台
- 任务 15：我的数据

## 实施内容

### 1. 任务广场

支持：

- 任务搜索
- 标签筛选
- 状态筛选
- 任务卡片/表格展示
- 任务领取

### 2. 标注工作台

工作台布局：

- 左侧题目列表或导航
- 中间 schema 表单
- 右侧辅助信息和提交区

核心能力：

- 上一题
- 下一题
- 跳题
- 草稿自动保存
- 手动保存
- 提交前校验
- 提交反馈

### 3. 打回修改

支持：

- 查看打回原因
- 查看上一轮审核意见
- 回填历史答案
- 修改后重新提交

### 4. 我的数据

展示：

- 已提交
- 已通过
- 已打回
- 待修改
- 历史提交记录

## 产出

- 标注员任务入口
- schema 驱动的标注工作台
- 草稿保存与恢复
- 提交和打回修改流程
- 我的数据统计与列表

## 验收标准

- 标注员可以完成“领取任务 -> 作答 -> 草稿保存 -> 提交”
- 页面刷新后草稿能恢复
- 表单校验失败能定位到字段
- 打回任务能看到原因并重新提交

## 风险

- 草稿保存失败会直接影响用户信任
- 大表单渲染需要控制性能
- 打回修改必须区分历史答案和当前编辑答案
