# 阶段五：审核闭环

## 目标

让审核员可以完成审核队列处理、详情查看、通过、打回、修订和批量操作。

## 覆盖任务

- 任务 16：审核队列
- 任务 17：审核详情

## 实施内容

### 1. 审核队列

支持：

- 待审列表
- 进行中列表
- 已完成列表
- 异常列表
- 搜索和筛选
- 批量通过
- 批量打回

### 2. 审核详情

展示：

- 原始题目数据
- 标注结果
- 标注员信息
- 提交时间
- AI 预审结果入口
- 历史审核意见
- 审计时间线

### 3. 审核动作

支持：

- 通过
- 打回
- 修订
- 转人工复核
- 填写审核原因

### 4. 审核状态流转

需要清晰展示：

- 当前审核状态
- 当前审核层级
- 上一轮审核意见
- 后续流转方向

## 产出

- 审核队列页面
- 审核详情页面
- 审核操作组件
- 审核意见和状态流转展示
- 批量审核能力

## 验收标准

- 审核员可以完成“查看待审 -> 打开详情 -> 通过/打回”
- 打回必须填写原因
- 批量操作有确认和结果反馈
- 审核历史可回看
- 标注员侧能看到打回原因

## 风险

- 批量操作要避免误触
- 审核状态如果和标注状态不同步，会破坏闭环
- 多级审核需要在 UI 上明确当前层级
