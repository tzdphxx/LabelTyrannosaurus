# 阶段六：AI、审计、导出与总验收

## 目标

补齐 AI 预审结果展示、审计日志、导出中心和项目级验收，形成完整交付版本。

## 覆盖任务

- 任务 18：AI 预审面板
- 任务 19：审计日志与导出中心
- 任务 20：端到端验收、测试、文档和构建检查

## 实施内容

### 1. AI 预审面板

展示：

- 总体结论
- 评分维度
- 每个维度分值
- AI 建议
- 风险提示
- 原始 Prompt
- 结构化返回值
- 人工复核结论

### 2. 审计日志

展示：

- 操作人
- 操作角色
- 操作时间
- 状态变化
- 操作原因
- 关联任务和提交

### 3. 导出中心

支持：

- JSON
- JSONL
- CSV
- Excel
- 导出任务创建
- 导出进度展示
- 导出历史查询
- 下载入口
- 字段映射配置

### 4. 总体验收

完成：

- 核心流程自测
- 组件级测试
- 集成测试
- 构建检查
- 文档更新

## 产出

- AI 预审展示面板
- 审计日志页面
- 导出中心页面
- 字段映射配置
- 测试用例
- README 和相关文档更新

## 验收标准

- AI 预审结果可解释、可回看
- 审计日志能串起关键状态变化
- 导出任务有进度和历史
- 四种导出格式入口完整
- Owner、Labeler、Reviewer 三条主流程均可跑通
- 构建和 lint 通过

## 风险

- AI 结果可能缺失或异常，前端需要降级展示
- 导出任务是异步长任务，需要处理超时和失败
- 审计日志如果字段不统一，会影响后续追踪
