## 6. 部署概况

演示环境采用前后端分离部署方式，前端页面和后端接口通过同一公网入口对外提供服务。

| 模块 | 部署说明 |
| --- | --- |
| 前端 | React + Vite 构建后的静态资源，由 Nginx 提供访问 |
| 后端 | Spring Boot 服务，采用容器化方式运行 |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis |
| 文件存储 | 腾讯云 COS |
| 反向代理 | Nginx |

服务器环境：

| 项目 | 内容 |
| --- | --- |
| 操作系统 | Linux |
| CPU | 2 核 |
| 内存 | 2 GB |
| Docker 版本 | 26.1.3 |
| Nginx 版本 | 1.20.1 |
| Java 运行环境 | Eclipse Temurin 21 JRE |

### 7.2 业务链路

演示环境支持以下端到端链路：

- 管理员登录并查看平台基础管理能力。
- 任务负责人完成模板搭建、任务创建、任务发布和结果导出。
- 标注员完成任务领取、在线作答、草稿保存和提交。
- 系统完成 AI 自动预审并生成审核意见。
- 审核员完成待审数据查看、人工审核、打回和通过。
- 平台记录关键状态流转和审核过程。

## 8. 演示环境边界

1. 本环境为课题评审演示环境，系统数据为测试数据。
2. 演示账号仅供评审体验使用。
3. 演示过程中产生的数据用于展示系统流程，不作为真实生产数据使用。
4. AI 自动预审使用线上模型服务，评审时可在页面查看实际调用后的审核结果。
