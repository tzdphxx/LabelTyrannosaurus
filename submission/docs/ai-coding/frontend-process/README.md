# 前端开发过程索引

前端过程记录围绕工作台主线整理，重点记录 AI 在需求拆解、方案比较、边界收敛、交互验证和风险修正中的使用方式。

## 文件说明

- `01-foundation-owner-process.md`：基础工程、角色工作台、Owner 任务与模板入口的过程记录。
- `02-dynamic-form-labeler-process.md`：动态表单、模板设计器、标注工作台、草稿和提交闭环的过程记录。
- `03-ai-reviewer-quality-process.md`：AI 前置审核、人工复核、审核历史、质量验证和导出审计协同的过程记录。

## 统一口径

- 前端按 Admin、Owner、Labeler、Reviewer 四类角色组织入口、导航和页面权限。
- 动态表单以同一份 schema 驱动设计态、预览态、作答态和只读回看态。
- AI 审核在前端表现为结构化结果分流和可解释面板，不在浏览器侧直接调用模型。
- Reviewer 侧同时承载人工复核队列和 AI 自动预审队列：人工队列处理需要人工复核的提交，AI 队列展示待审核、已通过、已打回、转人工和失败记录。
- 导出与审计纳入 Owner 侧工作台口径：前端提供任务级直接导出入口和下载反馈，后端承接导出历史、下载链接和审计追溯。
